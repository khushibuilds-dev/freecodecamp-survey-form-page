# Remote Work Experience Survey Form

A structured, accessible web survey form built with semantic HTML5 to gather user feedback and insights on remote work environments.

## Features
* **Personal Details Section:** Collects user Name, Email, and Age with built-in HTML5 form validation (`required`, `type="email"`, and `min`/`max` number limits).
* **Organized Fieldsets:** Groups related questions cleanly using `<fieldset>` and `<legend>` tags for better readability and screen-reader accessibility.
* **Interactive Input Types:** Includes text inputs, radio buttons (employment status and recommendations), checkboxes (remote work benefits), a role selection dropdown, and a multi-line comment textarea.
* **Accessible Labels:** Every form control is properly linked with a `<label>` element using matching `for` and `id` attributes.

## Technologies Used
* **HTML5:** Semantic form elements (`<form>`, `<fieldset>`, `<legend>`, `<select>`, `<textarea>`) and native client-side validation.
